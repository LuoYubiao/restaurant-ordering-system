# 餐饮小店点菜系统

一套给小餐馆、奶茶店、小吃店使用的「点菜 + 后厨出餐 + 菜品管理」系统。
不需要联网、不需要注册、不需要数据库服务器，**解压即用**。

---

## 一、这是做什么的？

- **柜台点菜页**：老板/收银员在电脑或平板上点菜下单。
- **厨房看板页**：后厨的屏幕实时显示新订单，做好后点一下即可标记出餐。
- **营业统计页**：查看营业额、单数、客单价、每日趋势与菜品销量排行。
- **菜品管理页**：增删改菜品、分类、价格，标记某个菜卖完了。
- **系统设置页**：设置店名、端口、打印机。
- **小票打印**：下单后自动打印「柜台小票」和「厨房小票」（支持模拟打印，没有打印机也能先用）。

提供给非程序员使用，日常操作全部在浏览器里完成。

---

## 二、解压即用（推荐）

1. 把整个压缩包解压到任意文件夹（例如桌面）。
2. 双击目录里的 **`restaurant-ordering-system.exe`**（Windows）即可。
3. 屏幕上会弹出一个黑色窗口，并自动打开浏览器进入点菜页。
4. **关闭这个黑色窗口 = 停止服务**，请勿在营业期间关闭。

> 第一次启动时，如果 Windows 弹出「防火墙提示」，请选择 **允许访问**（专用网络）。
> 否则同一局域网里的厨房屏幕将无法打开看板。

启动后窗口里会显示几个网址，例如：

```
============================================
  我的小店 点菜系统已启动
  柜台点菜：http://127.0.0.1:8000/counter
  厨房看板：http://192.168.1.10:8000/kitchen
  菜品管理：http://192.168.1.10:8000/admin
  系统设置：http://192.168.1.10:8000/settings
  关闭此窗口即停止服务
============================================
```

- 显示 `127.0.0.1` 的网址只能在**这台电脑**上打开。
- 显示 `192.168.x.x` 的网址可以在**同一局域网**的手机/平板/另一台电脑上打开（厨房看板就用它）。

## 三、源码方式启动（开发者）

需要有 Python 3.11 以上版本。

```bash
cd backend
# 创建并激活虚拟环境（首次）
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 启动
python -m app                   # 或： python run.py
```

常用参数：

```bash
python -m app --port 8080       # 指定端口
python -m app --host 127.0.0.1  # 只允许本机访问
python -m app --no-browser      # 不自动打开浏览器
python -m app --reload          # 开发模式，改代码自动重启
```

运行测试：

```bash
cd backend
./.venv/bin/python -m pytest -q
```

打包成「解压即用」的免安装版本（详细说明见 [scripts/README.md](file:///Users/yubiao/Develop/github_home/restaurant-ordering-system/scripts/README.md)）：

```bash
bash scripts/build.sh          # macOS / Linux
scripts\build.bat              # Windows
```

产物为 `dist/restaurant-ordering-system-macos.zip`（Windows 为 `-windows.zip`），解压后双击目录内的可执行文件即可运行。

## 五、打印机配置

系统内金额一律以「分」为单位存储（例如 12.50 元存为 1250），打印时自动格式化为两位小数。

打开 **系统设置页**，可以设置：

| 设置项 | 说明 |
| --- | --- |
| 打印机模式 | `模拟`（默认，不连打印机，小票存成文本文件）/ `网口` / `USB` |
| 打印机 IP | 网口打印机的 IP 地址，例如 `192.168.1.200` |
| 打印机端口 | ESC/POS 默认 `9100` |
| USB 厂商/产品 ID | USB 打印机需要，通常可从说明书或系统设备信息查到 |
| 纸张宽度 | `58` 毫米 或 `80` 毫米 |

小票内容：

- **柜台小票**：店名、订单号、桌号、下单时间、每道菜（菜名 × 数量 单价 小计）、合计、备注、页脚「谢谢惠顾」。
- **厨房小票**：店名、桌号（大字）、下单时间、每道菜（菜名 × 数量，**不含价格**）、口味备注。

**先用「模拟」模式就能跑通全流程**：每次打印会在项目根目录的 `printed/` 下生成一个 `时间_类型.txt` 文件，可打开查看排版是否正确，确认无误后再切到网口/USB 模式。

## 六、数据备份

- 所有业务数据都在 **`data/restaurant.db`** 这一个文件里（SQLite）。
- 备份方法：**复制整个 `data/` 文件夹**即可。
- 恢复方法：关闭程序，把备份的 `data/` 文件夹覆盖回去，再启动。
- 建议每天打烊后复制一次，存到U盘或网盘。

> 配置（店名、打印机等）在项目根目录的 `config.json`，如需迁移到新电脑，把它一起复制过去。

## 七、常见问题

**1）厨房/手机打不开看板，提示无法访问？**
- 确认厨房设备与这台电脑连的是**同一个 Wi-Fi/局域网**。
- 检查 Windows 防火墙：第一次启动要选择「允许访问」；若已误点拒绝，可在「Windows 防火墙 → 允许应用通过防火墙」里放行本程序。
- 确认电脑没有被设置为「公用网络」隔离（可在网络设置里改为「专用网络」）。

**2）提示端口被占用 / 页面打不开？**
- 程序启动时会自动从配置端口向后寻找可用端口，并打印实际使用的端口，请以窗口里显示的网址为准。
- 也可手动指定：`python -m app --port 8081`。

**3）打印机连不上？**
- 确认打印机电源已开、纸张装好。
- 网口打印机：确认 IP 与电脑在同一网段，可在浏览器输入打印机 IP 检查；确认端口为 `9100`。
- USB 打印机：确认已填入正确的厂商/产品 ID，并已安装驱动。
- 暂时无法解决时，先把打印机模式切回 **模拟**，业务可以照常进行，小票会存成文本文件。

**4）小票中文乱码？**
- 所用打印机需支持 GB18030 中文编码；请确认纸张宽度设置与实际纸张一致。

**5）数据会不会丢？**
- 数据保存在本机文件中，不依赖网络。只要定期备份 `data/` 即可。
